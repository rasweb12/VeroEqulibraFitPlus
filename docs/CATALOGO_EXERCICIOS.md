# Catálogo de exercícios

Semente auditada: 5 exercícios do Vero, 1 alias e nenhuma mídia associada. A ordem obrigatória é ID, nome normalizado, alias, equipamento/músculo, similaridade, confirmação do usuário e somente então Gemini. O endpoint inicial `POST /api/v1/exercises/search-before-ai` devolve `existing_match` ou `needs_clarification`; não inventa IDs.
