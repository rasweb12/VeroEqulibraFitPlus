# P3 — Catálogo nutricional

Estado: **BLOQUEADO — fonte licenciada ainda não selecionada**.

Não há valores nutricionais pré-cadastrados no novo produto. Para evitar números inventados, o aplicativo mantém o cadastro manual e as sugestões Gemini como estimativas que exigem revisão humana.

Antes de importar alimentos brasileiros, a equipe deve escolher uma fonte com licença e versão documentadas, definir atribuição quando necessária e validar o mapeamento para alimento, alias, marca, porção, código de barras, macros, fibras e origem do dado. Nenhuma tabela de catálogo será populada com exemplos artificiais.
