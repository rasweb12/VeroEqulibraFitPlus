# Mapeamento de exercícios legados

Os IDs abaixo continuam válidos para fichas e histórico existentes. Novos exercícios usam IDs canônicos `exercise-NNN`.

| ID legado | ID canônico | Exercício |
|---|---|---|
| biceps-curl | exercise-120 | Rosca direta com barra reta |
| calf-raise | exercise-050 | Gêmeos em pé na máquina |
| deadlift | exercise-171 | Levantamento Terra (Deadlift) tradicional |
| incline-dumbbell | exercise-086 | Supino inclinado com halteres |
| lat-pulldown | exercise-058 | Puxada alta na polia frontal (pegada aberta) |
| leg-press | exercise-005 | Leg Press 45° tradicional |
| seated-row | exercise-073 | Remada baixa na polia com triângulo |
| shoulder-press | exercise-102 | Desenvolvimento com halteres sentado |
| squat | exercise-001 | Agachamento livre com barra |
| triceps-pushdown | exercise-139 | Tríceps na polia alta com barra reta |
