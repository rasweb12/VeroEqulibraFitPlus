# P3 — Scanner de código de barras

Estado: **PARCIAL**.

Android usa `mobile_scanner` para leitura local de EAN-8, EAN-13, UPC-A e UPC-E. O código é mostrado ao usuário e há alternativa para registro manual.

A integração de catálogo por código permanece desabilitada. Open Food Facts foi avaliado como possível fonte, mas seu uso exige User-Agent identificável, respeito a limites, atribuição e análise da licença ODbL antes de qualquer persistência ou combinação de dados. Não há produtos ou nutrientes simulados no aplicativo.
