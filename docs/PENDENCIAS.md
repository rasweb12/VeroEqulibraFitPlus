# Pendências

- Integrar a fila Isar às ações de plano, hábitos, refeições e sessões, com persistência local cifrada e sincronização de conflitos. Fichas, exercícios personalizados, refeições, hidratação e mobilidade agora usam o keystore/keychain pelo adaptador `SecureOwnerStore`, com chaves separadas por conta; a outbox, os tombstones remotos e a resolução entre dispositivos continuam pendentes.
- Implementar fotos de evolução com consentimento, armazenamento cifrado e controle de retenção. Medidas corporais locais já estão disponíveis, mas fotografias não devem ser incluídas antes dessas garantias.
- Configurar provedor transacional isolado para confirmação de e-mail e recuperação de senha e executar testes REST autenticados ponta a ponta. As migrations de identidade e Data Protection foram aplicadas ao Neon isolado em 2026-10-16. Cadastro, login, JWT, refresh token com rotação, logout, sessão e exclusão de conta já estão implementados, mas não homologados ponta a ponta.
- Conectar alimentação, hábitos e administração à API autenticada. A API já possui endpoints autenticados para fichas e refeições, isolados pelo `sub`/`NameIdentifier` do JWT; o Flutter ainda precisa trocar o repositório local pelo cliente REST após o login. O Coach já possui fluxo Flutter → API .NET → FastAPI Gemini, mas requer sessão JWT e configurações de ambiente para execução real.
- Completar metadados técnicos de mídia com ffprobe e associar os demais vídeos a exercícios estáveis. As cinco associações verificadas do catálogo inicial (supino inclinado com halteres, agachamento com barra, leg press, puxada frontal e rosca direta) já têm player local no app.
- Validar em execução real a comunicação API → FastAPI privada → Gemini após o redeploy, sem registrar chaves ou conteúdo pessoal nos logs. Credenciais existentes nos projetos de origem não foram reutilizadas.
